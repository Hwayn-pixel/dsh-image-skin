# 🦊 幻弈的设计语言 · v1

> 2026-09-26 立。小肖说："形成你自己喜欢的设计语言，未来所有都这样来。"
> 所以这不是一次改版说明，是**规矩**——以后我做的每个界面都照它来。

## 一句话

**柔和、有呼吸；层次靠「光」和「间距」，不靠「线」。**

生硬感通常只有一个来源：**直角 + 高对比硬边**。所以我们反过来——凡是有轮廓的地方，一律给圆；凡是要分层的地方，先用底色和间距，线是最后手段。

---

## 一、圆角阶梯（4 的倍数，只准用这几档）

| token | 值 | 用在哪 |
|---|---|---|
| `--fx-r-xs` | **6px** | 小标签、色块、缩略图 |
| `--fx-r-sm` | **10px** | 输入框、按钮、分段控件 |
| `--fx-r-md` | **14px** | 卡片、面板 |
| `--fx-r-lg` | **20px** | 外层容器、弹窗 |
| `--fx-r-pill` | **999px** | 开关、胶囊、圆形图标按钮 |

**规则（来自 Harmonic / Telerik）**
- **交互元素一定带圆角**；非交互的标签/分隔可以直角——圆角本身就是"可以点"的信号。
- **四个角必须一致**，除非刻意做一个形状。
- **嵌套要递减**：内层圆角 = 外层 − 6px 左右（外 20 → 内 14 → 内小件 8），这样两层看起来是"套"在一起的，不是贴上去的。

## 二、边界：少用线（来自 HPE）

> HPE 的设计系统明确写着：层级用 **间距 + 字体 + 底色** 来做，**尽量少用边框**。

- **默认无边框**。层级靠：① 底色差一档 ② 间距加大 ③ 字号/字重变化。
- 确需分隔时**只有一档**：`1px`，颜色是**半透明中性**（`rgba(128,128,128,.2~.3)`），**绝不用纯白**——白边正是"生硬"的元凶。
- 同屏的线要保持同色同粗细，不许一处 .18、一处 .5。

## 三、颜色与强调（来自 Harmonic）

- **强调色只给交互**：选中的分段、主按钮、开关打开态、焦点环。
- **非交互**（标签、说明、徽章）一律**中性灰**——别让一堆小色块把画面弄花。
- 文字对比：正文 ≥ 4.5:1，辅助小字 ≥ 3:1（这次提到 `.78~.85` 就是这个道理）。
- 控件本体对背景 ≥ 3:1（M3 无障碍线）。

## 四、光（阴影只有两种）

| 用途 | 值 |
|---|---|
| 贴边（卡片浮一点点） | `0 1px 2px rgba(0,0,0,.05)` |
| 浮起（弹窗、上浮元素） | `0 8px 24px rgba(0,0,0,.08)` |

**不用彩色阴影**，不用超过两层的堆叠。玻璃面（blur 20px）之上不再加阴影。

## 五、间距阶梯

`4 / 8 / 12 / 16 / 24 / 32`——**优先 `gap`，少用 `margin`**（margin 在响应式里会乱跑）。同一组内容用同一档。

## 六、过渡

所有可交互元素 `transition: .18s ease`，只动 `background / color / border-color / box-shadow / opacity`，**不动 `width/height`**（会抖）。

## 落到代码（token 表）

```css
body[data-dsh-image-skin]{
  --fx-r-xs:6px; --fx-r-sm:10px; --fx-r-md:14px; --fx-r-lg:20px; --fx-r-pill:999px;
  --fx-line:1px solid rgba(128,128,128,.22);
  --fx-shadow-1:0 1px 2px rgba(0,0,0,.05);
  --fx-shadow-2:0 8px 24px rgba(0,0,0,.08);
  --fx-gap-1:4px; --fx-gap-2:8px; --fx-gap-3:12px; --fx-gap-4:16px; --fx-gap-5:24px; --fx-gap-6:32px;
  --fx-t:.18s ease;
}
```

> 浅色/深色都不用改这套——圆角、间距、阴影语义与明暗无关。

## 边界（我知道我管不着的）

- DSH **自带的弹窗外壳**（直角 + 白边）不是我们画的；要改得覆盖它的容器，影响面大——**先不动**，等小肖点头。
- DSH 的原生滑块/侧栏高亮同理。
- 我们**能管的**：`.dshImgSkin-*` 这一整片自己的设置界面，以及我们已经拥有的 `--dsh-skin-*` token。
